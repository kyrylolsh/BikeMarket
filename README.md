# BikeMarket

BikeMarket is a web application for buying and selling bicycles.

## Features

- User registration and login (Firebase Authentication)
- Create, edit and delete listings
- Product catalog with search and filters
- Shopping cart
- Orders
- Favorites
- Real-time chat between buyer and seller
- Seller profiles

## Technologies

- React
- TypeScript
- Vite
- Firebase Authentication
- Cloud Firestore
- Tailwind CSS
- React Router

## Installation

```bash
npm install
npm run dev
